# Production

This folder contains codes for core paralellised simulation production. 

There are two modes: 
+ `batches_production`, the first and currently most stable version
+ `split_production`, meant to filter which events get propagated by a neutrino energy threshold for more production efficiency. More details in the respective folder.

##Configuration Choices

The scripts in this folder assume (but can be modified):
+ gamma of 1.4 for the energy spectrum
+ neutrino energies ranging from 100 GeV to 1 EeV, usually with the option to produce over or under 1 PeV 

Before production you should consider what energies the normalising flow handling the photon propagation can support.

In addition, the codes assume:
+ LeptonInjector for the neutrino injection, which was the default when these scripts were developed
+ Volume Injection within a can of radius 805 m and height of 3500 m

The latter decision was due to the fact that RangedInjection only produced 10-15% of the total injected events. Volume Injection, however, raises errors in the Bisection method. At the time this was written, Prometheus has switched to GENIE, where the effective volume is calculated. This hasn't been explored.

## batches_production.py
produces neutrino simulations in batches in separate cores. Simulated events are saved in the output file inside Prometheus in parquet format. 

The following arguments control:

+ the number of workers (--workers)
+ the total number of events (--total_events) or the number of events per worker (--events_per_worker). Note that if the total number of events isn't a multiple of the amount of workers, there might be slightly fewer simulations than expected.
+ the energy range (--energy)
  + "lower" (1e2-1e6 GeV) 
  + "upper" (1e6-1e9 GeV) 
  + default is "full" (1e2-1e9 GeV)
+ the zenith angle (--zenith) for
  + "upgoing" or
  + "downgoing" events
  + default produces both or "full"
+ the event type (--flavor)
  + "MuMinus" for muon neutrinos by default, which uses ranged injection
  + "NuEbar" for electron antineutrinos, which uses an injection cylinder

## `batches_production.py`

Generates neutrino simulations in parallel batches. The simulated events are written in Parquet format to the Prometheus output directory.

### Command-line arguments

| Argument                                      | Description                                                                                                                                                                                                                                                                     | Values / Default                                                            |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `--workers`                                   | Number of parallel workers used for the simulation.                                                                                                                                                                                                                             | Integer                                                                     |
| `--total_events` **or** `--events_per_worker` | Specify the simulation size by providing either the total number of events or the number of events generated by each worker. If `--total_events` is not a multiple of the number of workers, the total number of simulated events may be slightly lower than requested. | Integer                                                                     |
| `--energy`                                    | Energy range of the simulated neutrinos.                                                                                                                                                                                                                                        | `lower` (10²–10⁶ GeV), `upper` (10⁶–10⁹ GeV), `full` (10²–10⁹ GeV, default) |
| `--zenith`                                    | Zenith angle of the simulated events.                                                                                                                                                                                                                                           | `upgoing`, `downgoing`, `full` (default, both directions)                   |
| `--flavor`                                    | Neutrino flavour to simulate.                                                                                                                                                                                                                                                   | `MuMinus` (default, ranged injection), `NuEbar` (injection cylinder)        |
