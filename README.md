# Prometheus-ARCA

batches_production.py produces neutrino simulations in batches. You may choose the amount of workers (n_workers) and the total number of simulated events (n_events_total). Note that if the total number of events isn't a multiple of the number of workers, you may end up with fewer simulations than expected. You may also select the neutrino flavour by choosing the final_state_1 to be "MuMinus" for muon neutrinos or "NuEbar" for electron neutrinos. The initial zenith angle can be adjusted, with 0 degrees signifying upgoing events and 180 degrees, downgoing ones. Simulated events are saved in the output file of Prometheus in parquet format.
