# Prometheus-ARCA

batches_production.py produces neutrino simulations in batches. You may choose the amount of workers (n_workers) and the total number of simulated events (n_events_total). Note that if the total number of events isn't a multiple of the number of workers, you may end up with fewer simulations than expected. You may also select the flavour by choosing the final_state_1 to be "MuMinus" for muon neutrinos or "NuEbar" for electron antineutrinos. The initial zenith angle can be adjusted, with 0 degrees corresponding to upgoing events and 180 degrees to downgoing ones. Simulated events are saved in the output file inside Prometheus in parquet format.

coordinate_change.py overwrites the original arca.geo file with the corrected coordinates for Prometheus. The position of each DOM is determined by the average of its respective PMT coordinates. You may simply run the script by inputting the location of the real arca coordinate file. Note that it might be sensitive to how the file content is formatted and thus it might be best to check in advance that it works for your input.
