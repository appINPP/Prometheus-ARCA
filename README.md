# Prometheus-ARCA

This repository contains supplementary codes for the **Prometheus** neutrino simulation framework, adapted for ARCA.

It is organised into three main components:

* **setup**, containing installation instructions and experiment-specific modifications required to configure Prometheus for ARCA
* **production**, containing scripts for generating simulations 
* **data**, containing scripts for validation, processing and preparation of the simulation output for subsequent use in the GNN workflow

Each folder contains its own README with documentation on the available scripts, their purpose, usage, limitations and/or future work needed.

Additional documentation describing the Prometheus simulation workflow is available in my folder on Drive.
